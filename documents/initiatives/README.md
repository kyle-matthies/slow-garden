# Initiative records

One record per initiative from an [initiative wave](../operations/INITIATIVE_WAVE_2026-09.md).
Each file follows the [feature brief template](../templates/FEATURE_BRIEF_TEMPLATE.md) and
adds two sections:

- **Implementation receipt:** what was built, how it was verified, and what was not verified.
- **Follow-ups:** gaps, proposed decisions, and any migration or hosted change proposed but not applied.

Naming: `<NN>-<slug>.md`, matching the wave table. Status language follows
[documents/README.md](../README.md). A merged pull request is intermediate state; an
initiative is complete only when its acceptance evidence exists.
